1. Study of LAN and WAN
Local Area Network (LAN): A LAN connects computers and other devices within a limited area, such as a computer laboratory, office, library, or university building. Devices in a LAN can share data, services, and network resources through switches and other networking devices.
Wide Area Network (WAN): A WAN connects two or more LANs located in different geographical areas. Routers are commonly used to direct data between the connected networks. In this project, the Main Campus represents WAN 1 and the Branch Campus represents WAN 2. Each WAN contains two LANs, and the two campuses are connected through a WAN link.
2. Study of IP Address, Subnet Mask, and Default Gateway
IP Address: A unique numerical address assigned to a network device. It identifies the device and allows it to send and receive data. Every device in the same LAN must use a different IP address.
Subnet Mask: A value that separates the network part of an IP address from the device part. The subnet mask 255.255.255.0 is equivalent to /24 and is commonly used for local networks.
Default Gateway: The IP address of the router interface connected to the local network. A device sends data to the default gateway when the destination is outside its own LAN.
Example device configuration:
Setting	Value
IP Address	172.16.10.2
Subnet Mask	255.255.255.0
Default Gateway	172.16.10.1
